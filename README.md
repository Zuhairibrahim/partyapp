## 📋 نبذة عن المشروع

**حفلة** تطبيق فاخر لحجز قاعات الأفراح والمناسبات: تصفح القاعات ومقدمي الخدمات (تصوير، كاترينغ، فرق موسيقية...)، قارق الأسعار، احجز وادفع من التطبيق — كل شي بضغطة زر وبواجهة ذهبية أنيقة.

</div>

## 📋 About

**Party App (حفلة)** is a luxury wedding & events booking app: browse venues and service vendors (photography, catering, music...), compare prices, add to cart, and book — all in one elegant gold-themed app.

## ✨ Features | المميزات

- 🏛 Venue & hall discovery | اكتشاف القاعات والصالات
- 🎪 Featured vendors & providers | مقدمو خدمات مميزون
- 🛒 Cart & smart booking flow | سلة حجز ذكية
- 🔍 Advanced search | بحث متقدم
- 📅 Booking dates management | إدارة مواعيد الحجز
- 👤 Customer profiles | ملفات العملاء
- 🌙 Premium dark-gold theme | تصميم فاخر ذهبي داكن

## 🛠 Tech Stack

`Flutter` · `Firebase` · `Local Stores` · `Material 3`

## ⬇️ Download & Run | التحميل والتشغيل

```bash
git clone https://github.com/Zuhairibrahim/partyapp.git
cd partyapp
flutter pub get
flutter run
```

> 🔗 Admin panel: [partyapp_admin](https://github.com/Zuhairibrahim/partyapp_admin)
